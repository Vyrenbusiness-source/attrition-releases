# Security Policy

## Supported versions

Only the [latest release](https://github.com/Vyrenbusiness-source/attrition-releases/releases/latest)
receives fixes. The game updates itself at start and in the main menu, so most
players are on the newest version within a day.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No, please update |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub instead:

1. Open the [Security tab](https://github.com/Vyrenbusiness-source/attrition-releases/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected version and the steps to reproduce it.

Examples of what belongs here:

* ways to make the auto-updater install files that are not from an official release
* bugs in co-op or PvP networking that let another player run code, crash your
  game on purpose or read files on your computer
* save files or downloads that can be crafted to harm the player's system

Cheating, exploits that only affect the match itself, and ordinary crashes are
regular bugs. Please report those through the
[bug report form](https://github.com/Vyrenbusiness-source/attrition-releases/issues/new/choose).

You will get a reply in the advisory thread. Once a fix is released, the
advisory can be published with credit to you, if you want.
