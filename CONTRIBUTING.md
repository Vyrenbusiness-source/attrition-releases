# Contributing to ATTRITION

Thanks for playing and for helping make the game better. The most useful thing
you can do is tell us what broke and what you would like to see.

## Before you start

The source code of ATTRITION is not public. This repository holds the store
page, the release downloads and the issue tracker. That means:

* **Bugs and ideas** go into [issues](https://github.com/Vyrenbusiness-source/attrition-releases/issues/new/choose).
* **Pull requests** are welcome only for documentation and translations
  (this README, the files in this repository, wording fixes). Pull requests with
  game code cannot be merged.

Please search the [existing issues](https://github.com/Vyrenbusiness-source/attrition-releases/issues)
first. If your problem is already there, add a comment or a 👍 instead of
opening a new one.

## Reporting a bug

Use the **Bug report** form. A good report lets us reproduce the problem on the
first try. Please include:

1. **Version.** It is shown in the main menu, for example `1.0.159`. The game
   updates itself, so check that you are on the latest version.
2. **Mode.** Match, Co-op or PvP, and whether you were host or client in co-op.
3. **Steps to reproduce.** What you did, in order, right before it happened.
4. **Expected vs. actual.** What you expected and what happened instead.
5. **Graphics settings.** Quality preset, resolution and window mode.
6. **Screenshot or clip**, if the problem is visible.
7. **Log file.** Logs are written to
   `%APPDATA%\Godot\app_userdata\ATTRITION\logs`. Paste that path into the
   Windows Explorer address bar, then attach the newest `.log` file. For a crash,
   attach the log from that session.

One problem per issue, please. Two unrelated bugs in one report are easy to lose.

## Suggesting a feature

Use the **Feature request** form. Describe the situation in the game where you
missed something and what you would like to happen. "When I'm reloading behind
cover I can't tell how many rounds are left" helps more than "better HUD".

## Translations and documentation

Spotted a typo or an awkward sentence on the store page, or want to help with
the English version of the game? Open an issue or a pull request against the
Markdown files in this repository.

## Conduct

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
Security problems are not reported in public issues, see [SECURITY.md](SECURITY.md).
